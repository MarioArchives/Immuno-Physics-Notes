Section IX Population dynamics of pathogens and hosts

From one body to whole populations: the immunity a host population builds up decides which virus strains can spread next, and the viruses keep moving away from it. Full notes for this part are not written yet; the original text starts on page 46, and the model below can be explored alongside it.

A model to explore

In models of host–pathogen co-evolution, each infection leaves immune memory behind, and that memory protects against the infecting strain and, more weakly, its close relatives.
